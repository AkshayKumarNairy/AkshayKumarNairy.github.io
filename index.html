QA Engineer & AI Tooling Builder

I'm a QA Engineer at AutoScout24 / LeasingMarkt.de in Germany. My work spans Playwright E2E automation, CI/CD quality gates, and building AI-powered tools that make the entire QA workflow faster and smarter.

Over the past two years, I've evolved from maintaining nightly test suites to architecting a full Claude Code plugin ecosystem (quality-pack) used across the engineering team: automated test generators, AI ticket-to-test tracers, PR review validators, and exploratory testing agents.

I hold an M.Sc. in Intelligent Systems from TU Kaiserslautern — the foundation for my current focus on LLM-assisted testing and AI-native QA workflows.

Key Projects

Selected work from the past two years — from nightly test infrastructure to building AI-native QA tooling used across the engineering team.

🧹 2025 – 2026

quality-pack — AI QA Plugin Suite

Designed and built a Claude Code skill ecosystem for QA: playwright-test-generator (auto-generates & self-heals Playwright tests from ticket ACs), qa-automator (traces tickets against code and runs test cases), check-qa-copilot (validates all AI reviewer comments are resolved pre-merge), weekly-report, and browser-qa (browser-based exploratory testing agent).

Claude API Playwright Python TypeScript MCP
🎭 2024 – 2026

Playwright Nightly Test Framework

Maintained and extended 180+ E2E nightly tests covering search funnels, deals page filters, merchant workflows, and addons booking. Resolved a critical failure where 89 of 182 tests were broken due to P2 brand page selector drift. Added Datadog → Slack alerting for real-time failure notifications.

Playwright TypeScript Datadog GitHub Actions
🚦 2026

CI/CD Quality Gates

Built a GitHub Actions workflow that blocks PR merges when AI reviewer (Copilot) comments are unresolved — ensuring AI-generated feedback is always actioned before code ships. Also surfaced unit test coverage reports directly on GitHub PRs for full visibility.

GitHub Actions GitHub API CI/CD Code Quality
🗺️ 2026

Test Coverage Mapping & Migration

Mapped existing cockpit E2E tests to a use-case specification to surface coverage gaps visually. Migrated legacy Pest-style closure tests to structured PHPUnit classes, improving IDE support, discoverability, and long-term maintainability.
